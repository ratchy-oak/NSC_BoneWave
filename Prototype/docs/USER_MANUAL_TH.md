# คู่มือผู้ใช้ BoneWave

ทุกหน้าที่เกี่ยวข้องแสดง badge **ข้อมูลจำลอง / SIMULATED DATA** ผลเป็นป้ายกลุ่มตัวอย่างทดลอง ไม่ใช่คำวินิจฉัย และแทนแพทย์หรือ X-ray ไม่ได้

1. เปิดระบบด้วย `python -m streamlit run app.py`
2. หน้า **ภาพรวมระบบ** กดปุ่ม one-click เพื่อสร้าง ตรวจ เตรียม สกัด features ฝึกสามโมเดล และสร้าง exports
3. หน้า **สร้างข้อมูลจำลอง** ปรับจำนวน sample/repeat ได้ โดยใช้ seed 42
4. หน้า **นำเข้าและตรวจสอบข้อมูล** อัปโหลด CSV ได้หลายไฟล์ ระบบรายงานข้อผิดพลาดภาษาไทยโดยไม่หยุดทำงาน
5. หน้า **กราฟ S11 และ S21** เลือก measurement และดาวน์โหลด PNG
6. หน้า **การเตรียมข้อมูล** เลือก interpolation หรือ Savitzky–Golay; smoothing ปิดเป็นค่าเริ่มต้น
7. หน้า **การสกัดคุณลักษณะ** สร้างตาราง 22 signal features
8. หน้า **ฝึกและประเมินโมเดล** ดูจำนวน sample/measurement, split metadata, metrics และ confusion matrices
9. หน้า **ทดลองจำแนกตัวอย่าง** เลือก measurement และ model เพื่อดู synthetic group/probability
10. หน้า **ส่งออกผลลัพธ์** ดาวน์โหลด CSV, JSON, PNG และ Joblib
11. อ่านหน้า **ข้อจำกัดและคำชี้แจง** ก่อนสาธิตทุกครั้ง
