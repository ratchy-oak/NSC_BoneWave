# Defect tracking

Create a [GitHub bug report](https://github.com/ratchy-oak/NSC_BoneWave/issues/new?template=bug_report.yml) for a reproducible defect. Include reproduction steps, expected/actual results, environment, proposed severity, and evidence. Link the fix and passing regression test before closing it.

Count confirmed, distinct defects, not failed assertions, deprecation warnings, or duplicate reports. A failed test must first be investigated to distinguish product behavior from a test/environment problem. Do not infer historical bug totals from the test count.

Track defects and their current status in [GitHub Issues](https://github.com/ratchy-oak/NSC_BoneWave/issues). The stop-status defect is recorded in [issue #1](https://github.com/ratchy-oak/NSC_BoneWave/issues/1).
