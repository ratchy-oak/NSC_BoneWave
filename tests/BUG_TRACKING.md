# Defect tracking

Create a [GitHub bug report](https://github.com/ratchy-oak/NSC_BoneWave/issues/new?template=bug_report.yml) for a reproducible defect. The form becomes available after the template is pushed. Include reproduction steps, expected/actual results, environment, proposed severity, and evidence. Link the fix and passing regression test before closing it.

Count confirmed, distinct defects, not failed assertions, deprecation warnings, or duplicate reports. A failed test must first be investigated to distinguish product behavior from a test/environment problem. Do not infer historical bug totals from the test count.

No historical issues or defect totals are claimed by this document. This change prepares the issue form; it does not create a GitHub issue without a reproduced product defect.
