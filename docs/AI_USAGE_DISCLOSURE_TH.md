# การเปิดเผยการใช้ AI

เครื่องมือ AI ช่วยในการวางโครงซอฟต์แวร์ สร้างโค้ดเบื้องต้น จัดโครงเอกสาร และสนับสนุนการ debugging ทีมพัฒนาต้องตรวจ อ่าน และเข้าใจโค้ดทั้งหมดก่อนส่งงาน AI ต้องไม่ถูกใช้เพื่อสร้างหรืออ้างข้อมูลการทดลองจริง ผู้ป่วย ผลคลินิก ความแม่นยำทางการแพทย์ หรือผล NanoVNA ที่ไม่เคยเกิดขึ้น ทีมเป็นผู้รับผิดชอบการทดสอบ การตัดสินใจทางเทคนิค ความถูกต้อง การอ้างอิง และผลงานฉบับสุดท้ายทั้งหมด
